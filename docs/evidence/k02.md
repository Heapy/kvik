# K02 contract evidence

Date: 2026-10-22. Kotlin/Native 2.4.20, macos_arm64, Liberica JDK 25.0.4.

`python3 tools/test_contracts.py --java-home "$JDK" --konan-home "$KONAN"` compiled the common core and test sources directly to a native test executable. All 14 tests passed. They cover SHA-256 known answers, strict JSON and path handling, action invalidation, non-cacheable effects, graph failures, test/evidence completeness, Maven coordinate boundaries, worker version/status consistency and independent canonical action/tree/runtime vectors.

`.kvik/schema-tools/bin/python tools/check_schemas.py` passed all 11 schema examples, identity vectors, unsafe-path cases, invalid-success results and malformed-coordinate rejection cases. Python helper files also passed bytecode compilation.

A separate read-only consistency pass compared Kotlin types, schemas and the decision document. Its actionable findings led to shared worker-result types/parsers, successful-action schema constraints, nonempty/unique test evidence identities, test-count consistency, stricter coordinate schemas and strict unknown-field/version rejection for typed decoders. Tree path collisions and evidence completeness remain semantic validations beyond what JSON Schema can express; consumers must use the core validation rules.

These tests prove the initial data/identity contracts. They do not exercise a production scheduler, content store, resolver, launcher or compiler adapter. Those implementations and their integration gates remain pending.
