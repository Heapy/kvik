# K15 first slice: foreground library build/test sessions

This slice implements owned library build/test invocations, line/JSONL controls,
content polling, failure recovery and session isolation. It does **not** complete
K15: application launch/restart and runnable artifacts, source/build-plugin
recomposition and launch-descriptor handoff, raw single-key terminal controls,
and graph reuse remain separate slices. See `integration/foreground/README.md`
for protocol, ownership, freshness and filesystem limits.

## Implementation

The Kotlin/Native session loop launches existing build/test CLI commands and a
read-only snapshot observer through K03 ProcessHost. Slow full tool verification
and content hashing run in owned children. Controls remain responsive while
those children work. The loop keeps one active operation and one coalesced
pending operation; tests cannot be erased by a later coalesced build request.
Each operation receives exact normalized global/scoped pins, selected targets,
modules and budgets, a unique run directory and offline execution policy.
Resolution is never invoked by dev.

Session events have their own `schemas/v1/session.json`; authoritative child run
records/events are retained unchanged. Input status explicitly covers only
project inputs plus tools-document contents. It does not claim ongoing tool
inventory or runtime-composition freshness. Existing child verification and
verification queries remain authoritative.

The C boundary does not change inherited open-file flags. TTY streams are
independently reopened and checked against the inherited device; pipe operations
require exclusive reader/writer ownership, use readiness checks and bounded
writes. Child stdin is /dev/null and child outputs are private files. No termios
changes are made. Initialization failure restores descriptors and handlers.
There is no daemon or warm worker.

External shared CAS is allowed when disjoint from watched inputs. Read-only
ancestor inode/suffix comparisons reject existing, missing, case/Unicode and
symlink aliases before session output writes. This relies on trusted ancestors
stable through use, like the existing snapshot/materialization contracts.

## Reproduction

On the pinned macOS arm64 environment, from the isolated checkout:

```sh
./kvik --java-home /Users/yoda/.sdkman/candidates/java/25.0.4-librca \
  --konan-home /Users/yoda/.konan/kotlin-native-prebuilt-macos-aarch64-2.4.20 \
  --artifact-cache /Users/yoda/dev/pet/kvik/.kvik/tool-artifacts \
  --offline --print-runtime

/Users/yoda/dev/pet/kvik/.kvik/schema-tools/bin/python tools/test_foreground.py \
  --konan-home /Users/yoda/.konan/kotlin-native-prebuilt-macos-aarch64-2.4.20 \
  --java-home /Users/yoda/.sdkman/candidates/java/25.0.4-librca \
  --runtime /private/tmp/kvik-k15-foreground/.kvik/runtime/executables/77ac7a9245c4efa4c906e8c0173d5105dbe40b8c20fefbc16bca2405ebd38ff4/kvik.kexe \
  --fixture /Users/yoda/dev/pet/kvik/.kvik/tests/native-scope-review/case-6jrzkpwg
```

The optional real fixture must contain a passed two-module Native project,
tools.json, lock and declared source/resource directories with the original
`fixture.AnswerTest.dependencyAndInternalDeclaration` test. The harness copies
only declared inputs into new evidence directories and resolves its own empty
external dependency closure before starting sessions. It preserves the fixture.
`--skip-build` reuses the already-built native test/probe binaries.

## Verified checks

- Source-built composition `77ac7a9245c4efa4c906e8c0173d5105dbe40b8c20fefbc16bca2405ebd38ff4`;
  bootstrap reported 38.634 seconds for Native compilation. This is an observed
  check under concurrent local load, not a benchmark.
- Two Native protocol tests: strict control/request identity and coalescing that
  preserves test intent.
- Initialization failure preserves open descriptors and restores interrupt
  handlers. Real blocked worker plus descendant processes terminate after q,
  EOF, SIGINT, SIGTERM, coordinator SIGKILL and parent loss while stdin remains
  open. Separate concurrent sessions remain independently controllable.
- PTY line controls/help, normal shutdown, owner kill and parent loss preserve
  termios and inherited flags. Retained aliases to the exact pipe open-file
  descriptions preserve flags after owner kill. The harness primes output before
  measuring flags because Darwin's first ordinary pipe write sets the kernel's
  written-history bit (0x10000), independently of fcntl.
- Same-size preserved-mtime content edits produce failure and subsequent repair
  reruns; worker crash also recovers. Malformed JSON is diagnosed without ending
  the session. Oversized input closes at 4097 bytes. Non-reading stdout triggers
  bounded backpressure shutdown and retains the session journal.
- Session JSONL is schema-validated with contiguous sequence numbers. Tracked
  workers, guardians and descendants are checked to have stopped after shutdown.
- Six actual CLI store/input overlap cases reject before creating outputs:
  existing directories, missing paths, case aliases, Unicode aliases, generated
  .kvik input and a symlink alias.

The standalone final lifecycle evidence is retained at
`.kvik/tests/foreground/lifecycle-kye3m2dx`. Its six termination cases completed
in 0.27–0.36 seconds and non-reading stdout closed in 2.20 seconds. These observed
bounds do not cover uninterruptible kernel/filesystem stalls, killed/stopped
guardians or descendants deliberately escaping their process group.

The real compile evidence in this slice is Native; a composed JVM foreground
fixture is not claimed here. The session uses the existing target-neutral
build/test command boundary, but that does not substitute for a JVM integration
run. Full K15 application/recomposition gates remain open.


The final preflight refinement preserves arbitrary disjoint local stores. The
same physical-overlap helper runs before CAS construction in every build/test
child and before snapshot observation, not only at session startup. Capture
accepts an optional expected configuration digest and verifies it immediately
after reading configuration, before publishing metadata or source blobs. All ten
Native project-snapshot tests pass, including a new regression where configuration
changes after preflight: capture is indeterminate and the store receives zero
puts. The read-only observer rejects the same mismatch.

Reproduce this focused regression with:

```sh
python3 tools/test_project_snapshot.py \
  --konan-home /Users/yoda/.konan/kotlin-native-prebuilt-macos-aarch64-2.4.20 \
  --java-home /Users/yoda/.sdkman/candidates/java/25.0.4-librca
```

The session-control schema also rejects a trailing newline inside requestId,
matching the Native parser's printable-ASCII contract. Both schema validation and
Native protocol tests exercise this boundary.


A final actual run exposed a debounce error: a transient unavailable observer
followed by the original fingerprint queued a redundant operation. The controller
now compares confirmed observations against the last stable fingerprint, including
a stable null state. A deterministic real-child regression injects one unavailable
observation, restores identical input and proves only the original operation ran.
Sustained invalid configuration and later repair retain their separate retry
behavior. The failed run is retained at `lifecycle-3ga6q8jt`; it is not counted as
a passing end-to-end run.

The rebuilt debounce regression and complete synthetic lifecycle suite passed at
`.kvik/tests/foreground/lifecycle-_r7pw7dl` on the final sources.
